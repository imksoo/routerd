# IPv4 転送・NAT の独立 PVE 試験

実施日: 2026-11-02
対象リビジョン: `5ba9cf443120281704523263adf5525041f1c67e`

## 結果

独立クライアント VM224 から VLAN 3131 上で上流 VM220 へ通信し、routerd 1.5 の IPv4 転送と送信元 NAT を確認しました。

## 観測

- VM224 は DHCPv4 で `198.18.15.104` を取得
- VM224 から VM220 の `198.18.16.1` へ ICMP 3/3 応答
- 応答 TTL は 63
- VM220 の VLAN 3132 捕捉では、要求と応答の送信元・宛先が `198.18.16.2` と `198.18.16.1`

したがって、クライアントの `198.18.15.104` はルーターで送信元 NAT され、上流からの返信も同じ経路で復元されました。

## 復帰

VM220 は 13 資源の `Healthy` 構成へ戻しました。VLAN 3132 の試験用インターフェースと規則は撤去済みです。VM224 の VLAN 3131 設定は撤去し、以後の IPv6 試験用に停止状態で保持します。

## 未検証範囲

IPv6 の委任・RA・転送、上流喪失と復帰、DHCP リース期限切れ、物理装置の相互接続は未検証です。
