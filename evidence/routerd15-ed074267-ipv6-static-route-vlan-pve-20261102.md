# IPv6StaticRoute の現行版 PVE VLAN 実行記録

実行時の対象リビジョンは `ed0742671ef87d4e2f42e98afc46fab0687ac0df` です。VM219 では候補の `routerd` と実際の `systemd` サービスを使用しました。候補 `routerd` の SHA-256 は `6a5d1eb7c0149c97d30d6e8def8bb927551409461a5f00adcb0ca17ab887e500` です。

これは VM219、VM220、VM224 を用いた PVE の三 VM 試験です。VM219 は候補ルーター、VM220 は独立上流、VM224 は独立クライアントです。VM224 は PVE の VLAN 3131 アクセスポートへ接続し、VM219 と VM220 は VLAN 3131/3132 のタグ付き接続を使用しました。

## 構成

- VM219 の LAN/WAN: VLAN 3131 の `2001:db8:3131::1/64`、VLAN 3132 の `2001:db8:3132::1/64`。
- VM224 クライアント: VLAN 3131 の `2001:db8:3131::2/64`。
- VM220 上流: VLAN 3132 の `2001:db8:3132::2/64`、到達先ループバック `2001:db8:3150::99/128`。
- 候補の `IPv6StaticRoute`: `2001:db8:3150::99/128` を `2001:db8:3132::2`、装置 `rd15-wan`、メトリック 79 で導入。
- 候補の防火壁: LAN/WAN の明示的なゾーン、既定拒否、LAN から WAN への ICMPv6 許可を適用。VM220 は独立した試験用防火壁構成で VLAN 3132 の ICMPv6 を受け付けました。

## 観測結果

1. `routerctl apply --replace` は Healthy となり、候補は指定したゲートウェイ、装置、メトリックのカーネル経路を導入しました。
2. VM224 から VM220 の `2001:db8:3150::99` への ICMP は 3/3 成功しました。応答の TTL は 63 で、VM219 を経由した一ホップ転送を観測しました。
3. 空の 1.5 設定へ置換すると、候補所有の経路は消え、`routerd_filter` は入力・転送の既定拒否を維持しました。VM224 の新規 ICMP は失敗しました。
4. 同じ経路・防火壁構成を再適用すると、VM224 の ICMP は 3/3 で復旧しました。
5. `routerd` を再起動しても、候補は同じカーネル経路を再確認し、VM224 の ICMP は 3/3 成功しました。
6. VM219 の VLAN 3132 インターフェース `rd15-wan` を削除すると、Interface の状態は `Down`、理由は `InterfaceNotFound` となり、通信は停止しました。インターフェースを同名・同一 VLAN で戻すと、設定置換や `routerd` 再起動なしに 6 秒で経路が再導入され、VM224 の ICMP は 3/3 で復旧しました。

## 復元

VM219、VM220、VM224 はそれぞれ試験前スナップショットへ戻しました。VM219 の `/usr/local/sbin/routerd`、`routerctl`、`routerd-bgp` の SHA-256 はそれぞれ `a1cbdd287e777d9eb090512ec7b7fb69f2340f0f12a71ed5567a8e2dcd2626f8`、`7de346416d215f842deaee95f615dad4c5bbb3c8d78f376d2a43ded55554b8f9`、`615e5b90d75c055ae43a12df0c4012b74ed5ab4a3f91bed8e295f93d4d858e99` へ戻りました。VM219 の `routerd` と `routerd-dnsmasq`、VM220 の `routerd` は稼働状態です。VM224 は試験前どおり停止状態です。三つのスナップショット、試験用 ISO、作業ディレクトリを削除しました。

## 範囲外

- 動的経路、複数経路、IPv6 NAT、DNS、PPPoE、物理回線、FreeBSD は対象外です。
- この記録は一つの IPv6 静的経路と、その経路に必要な限定的な防火壁設定の実通信・撤回・復旧を示します。旧構成が意図した全セキュリティ機能の対照、Linux 全機能、製品全体の合格を示すものではありません。
