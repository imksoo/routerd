# routerd 1.5 Linux IPv6 PPPoE PVE 実通信試験

実施日: 2026-11-02（JST）

## 結果

`ea892a6bc0e9b62cb1c8ac292509d50f380921f5` の Linux 候補パッケージで、独立 VM220 の
`rp-pppoe` アクセスコンセントレーターとの PAP、IPCP、IPv6CP を確認しました。VM219 の
`ppp-v6` から対向 IPv6 リンクローカルアドレスへの ICMPv6 は 3/3 応答しました。

アクセスコンセントレーターを停止すると `ppp-v6` は 3 秒以内の観測で消え、`routerd` は
`ERROR` を公開しました。同じアクセスコンセントレーターを再起動すると、21 秒の観測で
`ppp-v6`、IPv6CP、ICMPv6 3/3 が復旧しました。この時間は製品目標値ではありません。

空の新規 1.5 構成への置換では `HEALTHY`、資源数 0 となり、`ppp-v6` と PPP 用の
ゾーン・許可規則が撤回されました。同じ IPv6 PPP 構成の再適用後、IPv6CP と ICMPv6 3/3 が
復旧しました。

## 対象と構成

- ソース改訂: `ea892a6bc0e9b62cb1c8ac292509d50f380921f5`
- パッケージ: `dist/linux-amd64/routerd-v20261027.1620-linux-amd64.tar.gz`
- パッケージ SHA-256: `505d386a29fa9d7506c3005389bf828d64689b011d7f0652643b5c0f160fc7a3`
- VM219: 現行候補。VLAN 3132 の `rd15-wan` 上で `ppp-v6` を作成
- VM220: VLAN 3132 の独立 `rp-pppoe` アクセスコンセントレーター。PAP と IPv6 を有効化
- 新規構成: `evidence/pve07-pppoe-ipv6.yaml`
- 撤回構成: `evidence/pve07-pppoe-ipv6-withdraw.yaml`

候補の防火壁は既定遮断です。試験構成は PPP 側の非信頼ゾーンを宣言し、`icmpv6` の
`echo-request` だけを候補自身への入力として許可しました。全許可や旧構成の読取り・変換は
使用していません。

## 観測

1. VM219 は `ppp-v6` を作成し、IPv6CP により対向リンクローカルアドレスを得ました。VM220 の
   `ppp0` は同じ対向関係を表示しました。
2. VM219 から `対向リンクローカルアドレス%ppp-v6` への ICMPv6 は 3/3 応答しました。
3. VM220 の `pppoe-server` と対応 PPP プロセスを停止すると、VM219 の `ppp-v6` は 3 秒以内の
   観測で不在となり、状態は `ERROR` でした。
4. 同じアクセスコンセントレーターを起動すると、VM219 は 21 秒の観測で再接続しました。新しい
   IPv6CP 対向アドレスへの ICMPv6 は 3/3 応答しました。
5. 空構成の適用では `HEALTHY`、資源数 0、`ppp-v6` 不在となりました。`routerd_filter` は
   既定遮断の空表として残りました。これは撤回後も入力・転送を許可しない設計です。
6. IPv6 PPP 構成の再適用後、`ppp-v6`、IPv6CP、限定 ICMPv6 許可規則、ICMPv6 3/3 が復旧しました。

## 準備時に検出・修正した事項

- 初回は仮想 CD-ROM が過去の ISO 内容を保持していました。VM219 を再起動し、現行 ISO の
  アーカイブ SHA-256 を確認してから導入し直しました。初回の結果は数えていません。
- 初期構成には PPP 側の ICMPv6 許可がありませんでした。IPv6CP は確立しましたが、既定入力遮断で
  ICMPv6 は失敗しました。限定許可を含む構成 `2f0de8b5` へ修正後に本試験を実施しました。
- 実サービスの構成パスは `/usr/local/etc/routerd/router.yaml` でした。存在しない
  `/etc/routerd/router.yaml` への書込みはサービス再起動前に失敗したため、状態変更はありません。

## 復元

VM219 と VM220 は試験前スナップショットへ戻しました。試験用 ISO、一時配置、作成した
スナップショット、ロールバックで再装着された古い試験用 CD-ROM を削除しました。両 VM の
既存 `routerd` は `active`、VM224 は停止状態です。

## 未確認範囲

この結果は PPP の IPv6CP リンクローカル通信、アクセスコンセントレーター停止・再開、構成撤回・
再適用に限ります。IPv6 プレフィックスの配布と LAN 転送、別実装のアクセスコンセントレーター、
CHAP、認証失敗、資格情報更新、MTU 境界、複数同時セッション、長時間障害、物理回線、FreeBSD、
PPPoE 全体、Linux 全体、置換可能品質全体は未確認です。
