防火墙速率限制与 ICMP 规则

此示例演示小型路由器的有状态 FirewallRule 编写方式。

  • 以单一多端口规则允许 HTTP 和 HTTPS
  • 仅允许来自 WAN 的 ICMP echo request
  • 对超过数据包速率或每来源连接数上限的 SSH 尝试执行 reject

完整的 YAML 位于 examples/firewall-rate-limit.yaml。

daemon 未启动时检查

以下命令由具有 sudo 权限的本地用户执行；它们不会连接或启动 daemon，也不会变更主机网络。

LAB_DIR="$(mktemp -d)"
sudo routerd validate --config examples/firewall-rate-limit.yaml
sudo routerd apply --config examples/firewall-rate-limit.yaml --once --dry-run \
  --state-file "$LAB_DIR/state.db" \
  --status-file "$LAB_DIR/status.json"
rm -rf "$LAB_DIR"

规则摘录

- apiVersion: firewall.routerd.net/v1alpha1
  kind: FirewallRule
  metadata:
    name: ssh-bruteforce-over-limit
  spec:
    fromZone: wan
    toZone: self
    protocol: tcp
    destinationPorts:
      - "22"
    action: reject
    rateLimit:
      rate: 8
      burst: 16
      unit: packet
      per: minute
      log: true
    connLimit:
      maxPerSource: 4
      log: true
