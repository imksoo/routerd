NTPServer

各资源的配置 · Kind/name · when · dependsOn

apiVersion: system.routerd.net/v1alpha1 · metadata.name

使用chrony或FreeBSD ntpd配置时间服务器与上游。

指定条件与引用关系

  • managed默认false；true须声明上游来源，static另须servers。监听与允许来源列表会合并，上游替代来源则按source顺序选择。
  • ntpd生成器不输出allowCIDRs限制，不能假设声明此列表就会对ntpd应用客户端ACL。
  • 动态来源模式下，上游值未解析本身不会停止生成服务器配置，可能没有上游。Applied表示配置/服务处理，不证明时钟已同步。

配置语法

这是说明用语法，不是可直接复制的YAML。未加括号的字段在父条目内必填；[ ... ]表示按条件可省略，<类型>为替换值，(a | b)表示选项。选填父条目内仍可能有必填子条目。条件必填、互斥与实际默认值请见下表；常规YAML请使用链接示例。

- apiVersion: system.routerd.net/v1alpha1
  kind: NTPServer
  metadata:
    name: "<name>"
  spec:
    [ allowCIDRFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ allowCIDRs:
        - <string>
    ]
    [ fallbackServers:
        - <string>
    ]
    [ listenAddressFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ listenAddresses:
        - <string>
    ]
    [ managed: <boolean> ]
    [ provider: ("chrony" | "ntpd") ]
    [ serverFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ servers:
        - <string>
    ]
    [ source: ("static" | "auto" | "dhcp" | "dhcpv6") ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

字段含义与默认值

选填父条目的必填子条目仅在使用父条目时需要。其他具体条件列于说明；[ ... ]选项仍可能需要择一。

YAML 指定要求 类型与限制 字段含义与默认值
spec.managed 选填 boolean 默认false，仅记录Observed，不配置或启动时间服务；管理文件与服务时设true。
spec.source 选填 string; enum=["static", "auto", "dhcp", "dhcpv6"] 默认static，使用servers。auto/dhcp/dhcpv6均依serverFrom解析值、fallbackServers、servers的顺序选择，不会自动查找DHCP来源。
spec.servers 条件必填 array 上游主机名或IP，默认空；managed=true且source省略或static时必填。各项须为非空白单一值，不是资源引用。
spec.serverFrom 选填 array 显式值来源列表，默认空。例如DHCPv4Client/wan的ntpServers或DHCPv6PrefixDelegation/wan-pd的sntpServers。仅用于auto/dhcp/dhcpv6，每个resource与field须存在。 此解析器不使用optional标记，缺值即选下一种替代来源。
spec.when 选填 object 启用条件，省略不设限制；state/all/any、unknown及时间条件请见共用条件参考。
spec.provider 选填 string; enum=["chrony", "ntpd"] 服务器实现，通常默认chrony，FreeBSD默认ntpd；ntpd仅支持FreeBSD。
spec.fallbackServers 选填 array 备用上游列表，默认空；auto/dhcp/dhcpv6的serverFrom无值时，优先于servers采用，不生成独立备用指令。
spec.listenAddresses 选填 array 静态监听IP，默认空；CIDR取其主机IP。解析结果为空时不生成bindaddress/interface listen指令，使用后端默认行为。
spec.listenAddressFrom 选填 array 额外监听地址来源，默认空，与listenAddresses合并。每项须有resource与field。已声明监听配置但合并结果为空时，为Pending/NoListenAddresses。
spec.allowCIDRs 选填 array 允许客户端CIDR列表，默认空。chrony生成各allow，ntpd生成配置不使用此列表。静态值在验证时仅检查非空白，不检查CIDR语法。
spec.allowCIDRFrom 选填 array 与allowCIDRs合并的CIDR来源，默认空。非optional来源缺值时为Pending/AllowCIDRFromPending；派生CIDR错误时为Pending/AllowCIDRFromInvalid。不接受没有前缀长度的裸IP。

实现: pkg/api/specs.go · pkg/config/validate_system.go · pkg/controller/chain/ntp.go
