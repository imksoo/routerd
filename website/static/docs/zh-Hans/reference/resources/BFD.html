BFD

各资源的配置 · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

通过 vtysh 配置及观察 FRR bfdd 会话，供 BGPPeer 故障处理使用。与 GoBGP 为不同后端，BFD Down 可触发 BGP 对等端重置。

指定条件与引用关系

  • 每个已声明 BFD 至少须由一个 BGPPeer.bfd 引用，BFD peer 必须符合该 BGPPeer 名称或其对等端地址。BGPDynamicPeer 没有 bfd 字段。
  • 支持 Linux/FreeBSD，需有 FRR bfdd/vtysh。无接口时为多跳，使用引用 BGPRouter.routerID 作为本机地址；直接 IP 对等端且无接口时要求恰有一个 BGPRouter。指定接口则为单跳。
  • BFD 仅检测自身会话故障，Up 不代表所有路由目标可达。GoBGP 在先前 BFD Up 或 BGP 已建立后观察到 Down 才处理，不将所有未知或启动状态视为 Down。

配置语法

这是说明用语法，不是可直接复制的YAML。未加括号的字段在父条目内必填；[ ... ]表示按条件可省略，<类型>为替换值，(a | b)表示选项。选填父条目内仍可能有必填子条目。条件必填、互斥与实际默认值请见下表；常规YAML请使用链接示例。

- apiVersion: net.routerd.net/v1alpha1
  kind: BFD
  metadata:
    name: "<name>"
  spec:
    [ detectMultiplier: <integer> ]
    [ interface: <string> ]
    [ minRx: <string> ]
    [ minTx: <string> ]
    peer: <string>
    [ profile: ("" | "fast" | "normal" | "slow") ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

字段含义与默认值

选填父条目的必填子条目仅在使用父条目时需要。其他具体条件列于说明；[ ... ]选项仍可能需要择一。

YAML 指定要求 类型与限制 字段含义与默认值
spec.peer 必填 string 必填纯 IP 地址或 BGPPeer/name 引用。BGPPeer 引用展开为其所有对等端地址，并从 routerRef 的 routerID 取得本机地址。直接对等端不接受主机名。
spec.interface 选填 string 可选单跳接口。建议 Interface/name，控制器会解析声明的 Interface.ifname；单独名称虽验证为逻辑接口，却会原样传给 FRR。省略使用多跳。
spec.profile 选填 string; enum=["", "fast", "normal", "slow"] fast 或省略：minRx=minTx=300ms、倍数 3；normal：500ms/500ms/3；slow：1000ms/1000ms/5。明确单独配置优先。
spec.minRx 选填 string 可选 Go duration 50ms–60000ms，覆盖配置的接收间隔并转为整数毫秒。省略使用 profile。这是 BFD 协议计时器，不是路由器重启期限。
spec.minTx 选填 string 可选 Go duration 50ms–60000ms，覆盖 profile 发送间隔，输出为整数毫秒。
spec.detectMultiplier 选填 integer; minimum=1; maximum=50 可选整数 1–50；解码为 0 或省略时使用 profile 默认值（3，slow 为 5）。为协商检测间隔倍数，不是 routerd 协调尝试次数。
spec.when 选填 object 可选的通用启用条件，省略表示无条件。state/all/any、引用验证与模式限制请见通用字段。
