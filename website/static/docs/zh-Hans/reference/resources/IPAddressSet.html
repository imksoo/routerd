IPAddressSet

各资源的配置 · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

在支持的 nftables NAT、路由及防火墙规则间共享固定与 DNS 解析的 IP 地址。不创建路由或启动 DNS 服务。

指定条件与引用关系

  • addresses 或 names 至少一条，两者可并用。地址为单个 IPv4/IPv6，不接受 CIDR。各配置列表内重复会被拒绝；解析结果则合并并去重。
  • 使用端以裸名称或 IPAddressSet/name 引用。支持的 nftables 使用端包含 LocalServiceRedirect、NAT44Rule/FlowDNATPinhole、EgressRoutePolicy 与 FirewallRule/FlowPinhole。未被引用时仅报告 Observed/referenced:false，不解析名称或创建内核集合。
  • 更新前须由使用端生成器创建 nftables 集合，否则为 Pending/SetMissing。名称通过 /etc/resolv.conf 查询 A/AAAA，不使用 DNSUpstream 引用。部分 DNS 失败仍可应用其余地址；全部失败则为 Pending/ResolveFailed，该轮不替换现有集合。

配置语法

这是说明用语法，不是可直接复制的YAML。未加括号的字段在父条目内必填；[ ... ]表示按条件可省略，<类型>为替换值，(a | b)表示选项。选填父条目内仍可能有必填子条目。条件必填、互斥与实际默认值请见下表；常规YAML请使用链接示例。

- apiVersion: net.routerd.net/v1alpha1
  kind: IPAddressSet
  metadata:
    name: "<name>"
  spec:
    [ addresses:
        - <string>
    ]
    [ names:
        - <string>
    ]
    [ refreshInterval: <string> ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

字段含义与默认值

选填父条目的必填子条目仅在使用父条目时需要。其他具体条件列于说明；[ ... ]选项仍可能需要择一。

YAML 指定要求 类型与限制 字段含义与默认值
spec.addresses 条件必填 array 可选的固定 IPv4/IPv6 列表，默认为空；names 为空时必填。IPv4 映射 IPv6 会转为 IPv4，不展开子网。
spec.names 条件必填 array 可选的 DNS 名称，默认为空；addresses 为空时必填。拒绝空名称与去除前后空白后的重复。A/AAAA 结果与固定值合并，不展开通配名称。
spec.refreshInterval 选填 string 可选 Go duration。默认为最小正 DNS TTL 的一半，最低 1m；无正 TTL 时视为 5m，因此为 2m30s。正配置值只能缩短周期，可低于 1m。0／负值可解析但不缩短。实际更新在控制器协调时执行。
spec.when 选填 object 可选的通用启用条件，默认无条件。state/all/any 与使用端启用行为请见通用字段。
