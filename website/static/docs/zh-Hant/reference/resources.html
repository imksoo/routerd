各資源的設定

資源寫在Router.spec.resources內。範例的名稱、介面、位址、憑證及對端設定必須依環境調整。必填表示在所屬物件內必須指定。跨資源參照與語意限制還須以routerd validate確認。

routerd validate --config router.yaml

JSON Schema · YAML

Router

apiVersion: routerd.net/v1alpha1
kind: Router
metadata:
  name: example
spec:
  resources:
    - apiVersion: net.routerd.net/v1alpha1
      kind: Interface
      metadata:
        name: lan
      spec:
        ifname: ens18
        managed: true

依用途分類，分類內按Kind名稱排序。這是閱讀順序，不代表YAML評估、相依或執行順序。

介面與位址

Interface

Interface

為既有OS介面提供metadata.name邏輯名稱，供其他資源參照，不建立實體介面。

IPv4StaticAddress

IPv4StaticAddress

在邏輯介面宣告靜態IPv4位址，由controller協調設定，不是DHCP租約。

SelfAddressPolicy

SelfAddressPolicy

描述供支援的靜態 DHCPv6 轉譯使用的有序自身位址選擇策略，不會指派介面位址。

VirtualAddress

VirtualAddress

維護靜態或選舉後的浮動位址。Linux 靜態使用 iproute2、VRRP 使用 keepalived；FreeBSD 使用 ifconfig/CARP。

VRF

VRF

宣告Linux VRF裝置、路由表與成員意圖。目前產生計畫/artifact識別並保護路由表，但沒有建立VRF/連接成員的controller；計畫輸出不證明VRF已建立。

WAN連線與位址取得

DHCPv4Client

DHCPv4Client

執行受管routerd-dhcpv4-client daemon，套用租約位址，以及選用的預設路由與主機DNS設定。

DHCPv6Address

DHCPv6Address

宣告主機DHCPv6 client取得的IPv6位址，與DHCPv6PrefixDelegation不同，不分配LAN前綴。

DHCPv6Information

DHCPv6Information

從使用同介面的DHCPv6-PD daemon取得AFTR、DNS、SNTP與搜尋網域資訊，不啟動獨立Information-request client。

DHCPv6PrefixDelegation

DHCPv6PrefixDelegation

在上行介面取得 IPv6 委派前綴。下游或主機位址須以 IPv6DelegatedAddress 衍生並套用，僅取得前綴不會向客戶端公告。

DSLiteTunnel

DSLiteTunnel

向 AFTR 以 IPv6 封裝 IPv4。通道設定、IPv4 預設路由、NAT 與連通檢查是不同事項。

IPv6DelegatedAddress

IPv6DelegatedAddress

從 DHCPv6PrefixDelegation 前綴衍生並安裝本機 IPv6 位址。

IPv6RAAddress

IPv6RAAddress

宣告主機接收IPv6 RA/SLAAC，屬於RA client，不是向LAN公告的IPv6RouterAdvertisement。

PPPoESession

PPPoESession

監督執行 routerd-pppoe-client，在 Linux 使用 pppd、FreeBSD 使用 mpd5，並公開協商的 IPv4 工作階段狀態。部分舊欄位僅影響手動 FreeBSD render 輸出，不影響此精靈路徑。

VPN與通道

IPsecConnection

IPsecConnection

產生 strongSwan swanctl 連線，並一併同步所有 routerd IPsec 連線。CHILD_SA 設為流量觸發的 trap；載入設定不代表 SA 已建立。

OverlayPeer

OverlayPeer

描述供 HybridRoute 與路徑 MTU 策略衍生使用的既有傳輸；本資源不自行建立 WireGuard、Tailscale、IPsec 或隧道。

TailscaleNode

TailscaleNode

透過 routerd 產生的 Linux systemd oneshot 或 FreeBSD rc.d 指令稿管理 Tailscale 註冊選項，再讀取 tailscale status --json。Tailscale/Headscale 伺服器端核准仍需另行處理。

TunnelInterface

TunnelInterface

建立並調和未加密的 IPv4 外層隧道及選用內層 IPv4 位址，metadata.name 為實際 OS 隧道名稱。

VXLANTunnel

VXLANTunnel

管理具有靜態泛洪目的地及選用橋接的 Linux VXLAN 裝置，不設定多播探索或動態 MAC 學習。

WireGuardInterface

WireGuardInterface

建立或設定 WireGuard 裝置，透過 wg setconf 套用完整對等端設定。位址指派與一般路由由其他資源設定。

WireGuardPeer

WireGuardPeer

定義已宣告 WireGuardInterface 上的對等端。AllowedIPs 設定 WireGuard 的加密路由；此控制器不會自動建立一般 IP 路由。

路由與路徑監控

BFD

BFD

透過 vtysh 設定及觀察 FRR bfdd 工作階段，供 BGPPeer 故障處理使用。與 GoBGP 為不同後端，BFD Down 可觸發 BGP 對等端重設。

BGPDynamicPeer

BGPDynamicPeer

定義 GoBGP 傳入動態鄰居接納群組，不是個別對等端或 WireGuard/SAM 授權身分。

BGPPeer

BGPPeer

在已宣告的 BGPRouter 設定一個或多個靜態 BGP 鄰居。

BGPRouter

BGPRouter

設定本機 GoBGP 執行個體、接納路由及本機起源廣告。核心安裝與遠端可達性不同於 BGP Established 狀態。

ClusterNetworkRoute

ClusterNetworkRoute

透過明確指定的下一跳，設定前往 Kubernetes Pod 與 Service 網路的 IPv4 路由。不會自動探索叢集 CIDR 或節點。

EgressRoutePolicy

EgressRoutePolicy

選擇或設定出口路由，實際行為取決於明確 mode 與 hostTraffic。

HealthCheck

HealthCheck

探測 IP 目標並發布 Healthy/Unhealthy 狀態供路由選擇。成功僅代表設定的協定與路徑通過。

HybridRoute

HybridRoute

將明確列出的 IPv4 目的網路展開為經 OverlayPeer 的主路由表 IPv4Route。

IPv4Route

IPv4Route

安裝 IPv4 單播或黑洞路由，可從資源狀態取得裝置與閘道。

DHCP配發、RA與租約同步

DHCPv4Relay

DHCPv4Relay

透過 dnsmasq 將 DHCPv4 請求轉送至明確指定的一個 IPv4 伺服器。

DHCPv4Reservation

DHCPv4Reservation

在已宣告的 DHCPv4Server 為一個 MAC 位址保留 IPv4 位址。

DHCPv4Server

DHCPv4Server

透過目前共用 dnsmasq 服務提供 IPv4 DHCP 集區、帶選擇條件的範圍與保留。

DHCPv4ServerLeaseSync

DHCPv4ServerLeaseSync

以 SSH 上的 rsync 將 DHCPv4 伺服器租約檔與現有固定保留狀態複製到對等主機，並非 DHCP 容錯移轉協定。

DHCPv6PrefixDelegationLeaseSync

DHCPv6PrefixDelegationLeaseSync

複製內建 DHCPv6-PD 客戶端租約快照到對等主機，供復原與接管。

DHCPv6Server

DHCPv6Server

使用共用 dnsmasq 程序提供 LAN DHCPv6 位址或資訊服務及相關 RA 行為。

DHCPv6ServerLeaseSync

DHCPv6ServerLeaseSync

以 SSH 上的 rsync 將 DHCPv6 伺服器租約檔複製到對等主機，並非 DHCP 容錯移轉協定。

IPv6RouterAdvertisement

IPv6RouterAdvertisement

設定 LAN 的 IPv6 路由器公告選項，並棄用先前委派的前綴。

DNS

DNSForwarder

DNSForwarder

依查詢名稱替一個 DNSResolver 選擇本機區域或上游 DNS 的規則。

DNSResolver

DNSResolver

具有 UDP 與 TCP 接聽端點、連接 DNSForwarder 規則的本機 DNS 服務。

DNSUpstream

DNSUpstream

供 DNSForwarder 參照的 DNS 伺服器端點；僅宣告不會啟動接聽或轉送查詢。

DNSZone

DNSZone

透過 DNSForwarder.zoneRefs 提供本機 A/AAAA 記錄及自動 PTR 回應；不是支援任意記錄類型、區域傳送或簽署的通用權威 DNS。

NAT與服務發布

IngressService

IngressService

以後端選擇與主動健康檢查公開 IPv4 TCP/UDP 端點，可搭配本機 DNS 與內部迴送 NAT。屬於第 4 層 NAT，不是 HTTP 反向代理或 TLS 終止。

IPAddressSet

IPAddressSet

在支援的 nftables NAT、路由及防火牆規則間共用固定與 DNS 解析的 IP 位址。不建立路由或啟動 DNS 服務。

LocalServiceRedirect

LocalServiceRedirect

以 nftables prerouting NAT 將指定介面收到的符合流量重新導向路由器本機服務連接埠。

NAT44FlowDNATPinhole

NAT44FlowDNATPinhole

從送出 IPv4 UDP 學習內部端點，依收到 UDP 的目的連接埠動態 DNAT。僅 Linux nftables，目前 PF 未實作此資源。

NAT44Rule

NAT44Rule

透過輸出介面或 EgressRoutePolicy 選定裝置轉換路由 IPv4 來源。NAT 本身不允許轉送，也不指派轉換位址。

NAT44SessionSync

NAT44SessionSync

使用 SSH 事件串流或持續執行的 conntrackd FTFW 對等連結複製 Linux conntrack 狀態，不是 FreeBSD PF 狀態同步。

PortForward

PortForward

將 TCP/UDP 連接埠轉送至單一 IPv4 端點，可選內部迴送 NAT。Linux 產生 DNAT 與轉送允許，FreeBSD 使用 rdr pass。

防火牆與用戶端控制

ClientPolicy

ClientPolicy

對選定或非例外用戶端套用訪客服務與路由目的限制。Linux 以設定的 MAC 識別，FreeBSD PF 需要明確 IP 身分。

FirewallFlowPinhole

FirewallFlowPinhole

為防火牆區域配對學習允許的返回 IPv4 UDP 端點，不轉換位址。僅 Linux nftables，目前 PF 省略此資源。

FirewallPolicy

FirewallPolicy

設定與區域及明確規則搭配的共用隱含防火牆選項。多個資源會彙總，不是獨立套用。

FirewallRule

FirewallRule

宣告區域路徑的具名允許、丟棄或拒絕規則，支援位址、協定、連接埠比對及 Linux 速率/連線條件。

FirewallZone

FirewallZone

將已設定介面歸入具名信任角色，用於產生防火牆規則。不建立 OS 介面或獨立路由、橋接網域。

系統與管理

ControlAPI

ControlAPI

啟用可讀狀態及變更設定的HTTP Control API，與Unix socket控制及WebConsole分開。

Hostname

Hostname

管理OS主機名稱，與Router.metadata.name及資源名稱不同。

ManagementAccess

ManagementAccess

宣告套用前管理連線中斷檢查所檢查的介面。此資源不建立管理接聽端或防火牆允許規則。

NTPClient

NTPClient

管理或觀察向上游同步時間的用戶端。

NTPServer

NTPServer

使用chrony或FreeBSD ntpd設定時間伺服器與上游。

Package

Package

確保所選OS套件已安裝，選取第一個os與執行主機完全相符的套件集合。

RouterdCluster

RouterdCluster

透過檔案租約與OS檔案鎖協調哪個routerd可以變更狀態，不是VRRP選舉或對端網路探索。

Sysctl

Sysctl

協調一項核心sysctl，並可寫入持久sysctl.d檔案；沒有指向其他routerd資源的參照欄位。

SysctlProfile

SysctlProfile

依名稱套用路由器用sysctl集合，並可逐鍵覆寫；不是依名稱參照Sysctl資源。

WebConsole

WebConsole

由routerd提供唯讀Web主控台，HTTP監聽與可變更設定的ControlAPI不同。

日誌與監控

FirewallEventLog

FirewallEventLog

啟用防火牆封包紀錄收集器，設定資料庫、Linux NFLOG 群組與規則產生時的紀錄選項。部分接受的篩選與封存欄位目前沒有執行期使用者。

LogRetention

LogRetention

清除操作記錄的SQLite資料列，並可在刪除前轉送保存；不管理任意OS記錄檔。

LogSink

LogSink

依type選擇操作事件記錄的輸出目的地，與ObservabilityPipeline內的記錄輸出設定不同。

ObservabilityPipeline

ObservabilityPipeline

結合受管服務的OpenTelemetry環境宣告與獨立內建操作事件記錄consumer。

Telemetry

Telemetry

為產生的受管服務設定OpenTelemetry環境變數，不定義LogSink或獨立collector程序。

TrafficFlowLog

TrafficFlowLog

將連線快照記錄至 SQLite 流量資料庫，並可從 DPI 快取補充資訊。不是封包擷取，也不記錄每個封包。

事件與事件聯邦

DerivedEvent

DerivedEvent

資源狀態條件改變時，發送成立或撤回事件。與 EventRule 不同，此處評估目前狀態而非事件序列。

EventGroup

EventGroup

宣告共用的聯邦事件群組，以及此路由器的識別、對等節點來源、接收與本機保留設定。

EventPeer

EventPeer

宣告 EventGroup 的一個遠端傳送目標。傳輸驗證與本機識別由群組提供。

EventRule

EventRule

從持久化的本機事件紀錄比對模式並產生事件，可依關聯鍵分開維護狀態。

EventSubscription

EventSubscription

從持久化資料庫比對尚未到期的聯邦事件，呼叫本機 Plugin，將結果儲存為 DynamicConfigPart。

FederationSLO

FederationSLO

設定 routerctl doctor 診斷聯邦配送與訂閱時使用的每群組門檻，不改變配送重試或 Plugin 執行策略。

SAM與行動性

MobilityPool

MobilityPool

結合共用 SAM 拓撲、本機所有權觀察及 BGP/聯邦狀態，規劃位址移動與本機擷取。YAML 是本機意圖，共用身分位於 SAMNodeSet。

SAMEnrollmentClaim

SAMEnrollmentClaim

宣告提交 SAM 註冊的 leaf 自有身分、傳輸與移動意圖。到期及撤銷是 RR/控制器管理狀態，不屬於 leaf join HMAC。

SAMEnrollmentClient

SAMEnrollmentClient

將本機註冊要求提交至啟動 RR ControlAPI，取得允許的拓撲，儲存為動態 SAMRRSet 及選用 direct 對等群組供既有控制器使用，不建立雲端基礎設施。

SAMEnrollmentPolicy

SAMEnrollmentPolicy

定義 RR 端 SAM leaf 身分、傳輸位址、選用 join 認證及允許移動所有權的接納邊界。leaf 使用接納拓撲，不複製此原則。

SAMNodeSet

SAMNodeSet

宣告供傳輸、事件對等端、WireGuard 與 MobilityPool 成員解析共用的 SAM 節點身分與拓撲。本機供應者擷取/探索設定應放在 MobilityPool 自節點覆寫，不放在此處。

SAMSubnetPolicy

SAMSubnetPolicy

將分片指派發布為聯邦事件，讓各節點將 MobilityPool 所有權探索限縮至負責的 IPv4 子網。這是探索範圍指派，不是 IP 路由資源。

SAMTransportProfile

SAMTransportProfile

從共用拓撲或接納的 RR/direct 快照衍生節點間 SAM 隧道、端點 /32 路由及選用 BGP/BFD。

擴充、動態設定與供應商操作

CloudProviderProfile

CloudProviderProfile

描述規劃供應商操作所用的身分及目標中繼資料預設值。此宣告本身不進行雲端驗證或建立資源。

DynamicConfigSource

DynamicConfigSource

宣告以外掛取得的動態設定來源。目前有型別解碼與驗證，但沒有讀取DynamicConfigSourceSpec的runtime處理，宣告本身不會執行外掛。

DynamicOverridePolicy

DynamicOverridePolicy

授權指定動態來源在動態部分有效期間遮蔽特定啟動設定資源，不改寫已儲存的啟動設定。

Plugin

Plugin

註冊實作routerd外掛協定的執行檔，由明確操作或EventSubscription等使用端呼叫。

ProviderActionPolicy

ProviderActionPolicy

控制交給執行 Plugin 的供應商操作。宣告政策本身不會執行操作或登入雲端。
