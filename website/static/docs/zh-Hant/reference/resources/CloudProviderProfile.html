CloudProviderProfile

各資源的設定 · Kind/name · when · dependsOn

apiVersion: hybrid.routerd.net/v1alpha1 · metadata.name

描述規劃供應商操作所用的身分及目標中繼資料預設值。此宣告本身不進行雲端驗證或建立資源。

指定條件與參照關係

  • provider、非空 capabilities、auth.mode 與 auth.command 必填。驗證會檢查宣告，但目前執行流程不執行 auth.command。供應商變更由受 ProviderActionPolicy 控制的獨立執行 Plugin 處理。
  • Mobility capture 等使用端以 metadata.name 選擇設定檔，不是共用狀態值來源。subscriptionID/resourceGroup 只補足未設定的操作目標值，不覆蓋明確值。

YAML定義

此處列出所有欄位的結構，不是可直接套用的設定範例。請替換佔位值、省略不使用的選項，並選擇相容的組合。顯示值只表示型別；有效預設值及條件列於下方欄位說明。必填標記來自JSON Schema，表示在所屬物件內必須指定；語意驗證可能要求其他欄位或參照。

- apiVersion: hybrid.routerd.net/v1alpha1
  kind: CloudProviderProfile
  metadata:
    name: "<name>"
  spec:
    auth: # 必填; object
      command: "<string>" # 選填; string
      mode: "external-command" # 必填; string; enum=["external-command"]
    capabilities: # 必填; array
      - "<string>" # string
    provider: "azure" # 必填; string; enum=["azure", "aws", "oci", "gcp"]
    resourceGroup: "<string>" # 選填; string
    subscriptionID: "<string>" # 選填; string

欄位意義與預設值

YAML 欄位意義與預設值
spec.provider 必填 azure/aws/oci/gcp，無預設值。選擇規劃／執行器標籤，不會自動探索憑證。
spec.subscriptionID 選用的目標訂閱 ID，預設空。僅在目標缺少 subscriptionId 時補入，不檢查存在或登入。
spec.resourceGroup 選用的操作目標 resourceGroup 預設值，預設空。不建立或驗證資源群組。
spec.capabilities 必填非空字串清單，不可含空項目。目前驗證不限制為已知能力詞彙，執行政策也不將它視為操作允許清單。
spec.auth 必填的驗證描述。目前實作僅驗證，不呼叫命令。
spec.auth.mode 必填 external-command，唯一接受的模式。不會將 auth.command 啟動為服務。
spec.auth.command 必填非空宣告，無預設值。目前執行流程不執行，也不傳遞由此取得的憑證。
