NAT44FlowDNATPinhole

各資源的設定 · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

從送出 IPv4 UDP 學習內部端點，依收到 UDP 的目的連接埠動態 DNAT。僅 Linux nftables，目前 PF 未實作此資源。

指定條件與參照關係

  • fromInterfaceRefs、outbound、inbound 與來源選擇器必填。介面與 IPAddressSet 參照須存在於同一 Router。僅 IPv4/UDP，屬於連接埠觸發 DNAT，不是一般 conntrack 回覆處理。
  • 映射鍵為送出本機 UDP 來源連接埠，值為 SNAT 前內部 IPv4 與相同連接埠。所有選定介面共用每資源一個映射。不同用戶端使用相同來源連接埠會覆寫，遠端位址不在鍵內。
  • 入站 DNAT 檢查選定輸入介面、允許的遠端來源連接埠與已學習目的連接埠。不會將送出目的 CIDR/集合重新套用到入站遠端位址，也不建立防火牆轉送允許；轉換流量仍需防火牆允許。
  • 學習映射是核心執行狀態，不是設定或持久化資料庫。重建 NAT 表或重啟會遺失，需送出流量重新學習。

設定語法

這是說明用語法，不是可直接複製的YAML。未加括號的欄位在父項目內必填；[ ... ]表示依條件可省略，<型別>為替換值，(a | b)表示選項。選填父項目內仍可能有必填子項目。條件必填、互斥與實際預設值請見下表；一般YAML請使用連結範例。

- apiVersion: net.routerd.net/v1alpha1
  kind: NAT44FlowDNATPinhole
  metadata:
    name: "<name>"
  spec:
    [ correlation:
        [ key: ("" | "localPort") ]
    ]
    fromInterfaceRefs:
      - <string>
    inbound:
      sourcePorts:
        - <string>
    outbound:
      [ destinationCIDRs:
          - <string>
      ]
      destinationPorts:
        - <string>
      [ destinationSetRefs:
          - <string>
      ]
      protocol: ("udp")
      [ sourceCIDRs:
          - <string>
      ]
      [ sourceSetRef: <string> ]
    [ timeout: <string> ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

欄位意義與預設值

選填父項目的必填子項目僅在使用父項目時需要。其他具體條件列於說明；[ ... ]選項仍可能需要擇一。

YAML 指定要求 型別與限制 欄位意義與預設值
spec.outbound 必填 object 必填的送出學習比對。記錄符合的 UDP 流量身分，但不會自行允許流量通過防火牆。
spec.outbound.sourceSetRef 條件必填 string 選用既有 IPAddressSet/ 來源選擇器。此欄或 sourceCIDRs 至少一者必填；兩者可作 OR。預設空。
spec.outbound.sourceCIDRs 條件必填 array 選用 IPv4 來源前綴 OR 清單，預設空，至少需要一個來源選擇器。拒絕 IPv6，產生時遮罩主機位元。
spec.outbound.destinationCIDRs 選填 array 選用學習用 IPv4 遠端目的，預設空。與 destinationSetRefs 作 OR；兩者皆無時任意遠端位址。
spec.outbound.destinationSetRefs 選填 array 選用既有 IPAddressSet/ 遠端目的參照，不可重複，預設空。來源與目的兩類以 AND 組合。
spec.outbound.protocol 必填 string; enum=["udp"] 必填 udp，無預設值。此學習機制不支援 TCP/IPv6。
spec.outbound.destinationPorts 必填 array 必填非空送出 UDP 目的連接埠：數字 1–65535 或唯一 start-end 範圍。範圍不可與其他項目混用。
spec.inbound 必填 object 必填返回流量比對。sourcePorts 選擇遠端 UDP 傳送者連接埠，不是本機目的連接埠。
spec.inbound.sourcePorts 必填 array 必填非空遠端 UDP 來源連接埠清單，與 outbound.destinationPorts 相同的 1–65535/單獨範圍限制。
spec.timeout 選填 string 選用嚴格為正的 Go 時間長度，預設 3m。每個符合送出封包更新學習項目。產生時四捨五入為秒且至少 1s；這是學習狀態到期，不是 UDP 協定逾時。
spec.when 選填 object 選用共用啟用條件，預設無條件。篩除資源不產生學習映射/集合規則。巢狀條件與結構描述限制請見共用欄位。
spec.fromInterfaceRefs 必填 array 必填非空輸出/輸入介面清單，接受單純名稱或 Interface/name、PPPoESession/name、DSLiteTunnel/name。送出比對 oifname，入站比對同清單的 iifname。
spec.correlation 選填 object 選用關聯物件，僅支援 localPort，省略亦使用相同鍵。
spec.correlation.key 選填 string; enum=["", "localPort"] 僅空或 localPort。產生器無其他分支，一律以 UDP 來源連接埠索引學習映射。
