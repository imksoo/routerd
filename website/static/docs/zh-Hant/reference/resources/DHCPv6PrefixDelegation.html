DHCPv6PrefixDelegation

各資源的設定 · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

在上行介面取得 IPv6 委派前綴。下游或主機位址須以 IPv6DelegatedAddress 衍生並套用，僅取得前綴不會向客戶端公告。

指定條件與參照關係

  • interface 須為既有邏輯介面名稱，預設 client 為 routerd-dhcpv6-client。亦識別 networkd、dhcp6c、dhcpcd 並產生平台設定，但即時監督與狀態通訊端以 routerd 常駐程式為主，生命週期支援不應視為等同。
  • profile/prefixLength 影響外部客戶端設定及還原快照比對。受監督的 routerd-dhcpv6-client 不接收 profile 或 prefix-length 旗標，取得時不以此提示長度；clientDUID 會傳入。
  • 不支援 iaid/duidType YAML 控制。routerd 常駐程式 IA_PD IAID 預設 1，未指定 clientDUID 時由上行 MAC 衍生 DUID-LL。required 不會實作阻擋開機的要求。

設定語法

這是說明用語法，不是可直接複製的YAML。未加括號的欄位在父項目內必填；[ ... ]表示依條件可省略，<型別>為替換值，(a | b)表示選項。選填父項目內仍可能有必填子項目。條件必填、互斥與實際預設值請見下表；一般YAML請使用連結範例。

- apiVersion: net.routerd.net/v1alpha1
  kind: DHCPv6PrefixDelegation
  metadata:
    name: "<name>"
  spec:
    [ client: <string> ]
    [ clientDUID: <string> ]
    interface: <string>
    [ prefixLength: <integer> ]
    [ profile: ("default" | "ntt-ngn-direct-hikari-denwa" | "ntt-hgw-lan-pd") ]
    [ required: <boolean> ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

欄位意義與預設值

選填父項目的必填子項目僅在使用父項目時需要。其他具體條件列於說明；[ ... ]選項仍可能需要擇一。

YAML 指定要求 型別與限制 欄位意義與預設值
spec.interface 必填 string 必填同一 Router 的邏輯上行介面。若 DHCPv6Address 亦使用同一介面，外部 dhcp6c/dhcpcd PD client 須與該資源 client 相符。
spec.client 選填 string 預設 routerd-dhcpv6-client，接受 networkd/dhcp6c/dhcpcd。目前監督亦可能合成 routerd DHCPv6 systemd 單元，選外部客戶端不普遍保證停用內建常駐程式。
spec.profile 選填 string; enum=["default", "ntt-ngn-direct-hikari-denwa", "ntt-hgw-lan-pd"] 空值/default、ntt-ngn-direct-hikari-denwa 或 ntt-hgw-lan-pd。NTT 在支援的產生路徑提供 /60 與 link-layer DUID 預設，不設定業者憑證或變更內建命令。
spec.prefixLength 選填 integer; minimum=1; maximum=128 選用 1–128，省略或 0 時 NTT 為 /60，default 無長度提示，不保證分配長度，也不傳入內建取得。HA 預置快照重用卻要求有效長度完全相同：default 省略時為 0，不符合一般委派前綴，此路徑須明確指定實際長度。
spec.clientDUID 選填 string 選用無分隔符且偶數長度的十六進位 DUID，拒絕冒號與空白。空值由內建客戶端從 MAC 衍生 DUID-LL，身分亦影響還原租約是否可重用。
spec.required 選填 boolean 布林值預設 false，會解碼但目前不作為必要性或開機等待策略。相依者應使用實際 Bound 狀態及相依條件。
spec.when 選填 object 選用共用狀態條件，預設無條件。監督客戶端依已解析條件篩選，條件為假可在保留宣告時停止取得。
