HybridRoute

各資源的設定 · Kind/name · when · dependsOn

apiVersion: hybrid.routerd.net/v1alpha1 · metadata.name

將明確列出的 IPv4 目的網路展開為經 OverlayPeer 的主路由表 IPv4Route。

指定條件與參照關係

  • 僅支援非預設 IPv4 CIDR，拒絕 default、0.0.0.0/0、IPv6 及非主表。目的前綴遮罩化後產生 <資源名>-，例如 branch-10-20-0-0-16。
  • 產生名稱須唯一，不可與明確 IPv4Route 名稱或目的衝突。同一 HybridRoute 內重複正規化目的也會衝突。HealthCheck 異常僅改變狀態，不阻擋安裝、撤回路由或改選對端。
  • 產生 IPv4Route 使用 peer.underlay.interface 作 device，僅 ipsec 可將 IPv4 remote.address 作 gateway，其他為裝置路由。須另行提供隧道/VPN 與實際可達性。Linux 使用正 metric，FreeBSD 底層 IPv4Route 不套用 metric。

設定語法

這是說明用語法，不是可直接複製的YAML。未加括號的欄位在父項目內必填；[ ... ]表示依條件可省略，<型別>為替換值，(a | b)表示選項。選填父項目內仍可能有必填子項目。條件必填、互斥與實際預設值請見下表；一般YAML請使用連結範例。

- apiVersion: hybrid.routerd.net/v1alpha1
  kind: HybridRoute
  metadata:
    name: "<name>"
  spec:
    destinationCIDRs:
      - <string>
    [ healthCheckRef: <string> ]
    [ install:
        [ metric: <integer> ]
        [ table: ("" | "main") ]
    ]
    peerRef: <string>

欄位意義與預設值

選填父項目的必填子項目僅在使用父項目時需要。其他具體條件列於說明；[ ... ]選項仍可能需要擇一。

YAML 指定要求 型別與限制 欄位意義與預設值
spec.destinationCIDRs 必填 array 必填非空且不含預設路由的 IPv4 CIDR 清單，不自動補遠端網路或探索。
spec.peerRef 必填 string 必填既有 OverlayPeer metadata.name 裸名；展開雖可正規化 OverlayPeer/name，一般跨資源驗證仍要求裸名。
spec.install 選填 object 選用路由安裝設定，預設主表、metric 0，不提供策略路由或自動 HA 選擇。
spec.install.table 選填 string; enum=["", "main"] 僅空值或 main，兩者均展開為主表 IPv4Route，拒絕其他表名或編號。
spec.install.metric 選填 integer; minimum=0 非負整數，預設 0，複製至產生 IPv4Route；Linux 僅輸出正值，FreeBSD 路徑忽略。
spec.healthCheckRef 選填 string 選用既有 HealthCheck 裸名，空值不附加健康狀態。unhealthy/failed/error 標示 Degraded 但不變更路由，此函式不將缺少或 unknown 狀態視為異常。
