防火牆速率限制與 ICMP 規則

此範例示範小型路由器的有狀態 FirewallRule 撰寫方式。

  • 以單一多連接埠規則允許 HTTP 和 HTTPS
  • 僅允許來自 WAN 的 ICMP echo request
  • 對超過封包速率或每來源連線數上限的 SSH 嘗試執行 reject

完整的 YAML 位於 examples/firewall-rate-limit.yaml。

daemon 尚未啟動時檢查

下列指令由具有 sudo 權限的本機使用者執行；它們不會連線或啟動 daemon，也不會變更主機網路。

LAB_DIR="$(mktemp -d)"
sudo routerd validate --config examples/firewall-rate-limit.yaml
sudo routerd apply --config examples/firewall-rate-limit.yaml --once --dry-run \
  --state-file "$LAB_DIR/state.db" \
  --status-file "$LAB_DIR/status.json"
rm -rf "$LAB_DIR"

規則摘錄

- apiVersion: firewall.routerd.net/v1alpha1
  kind: FirewallRule
  metadata:
    name: ssh-bruteforce-over-limit
  spec:
    fromZone: wan
    toZone: self
    protocol: tcp
    destinationPorts:
      - "22"
    action: reject
    rateLimit:
      rate: 8
      burst: 16
      unit: packet
      per: minute
      log: true
    connLimit:
      maxPerSource: 4
      log: true
