BGPRouter

Resource configuration reference · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

Configure the local GoBGP instance, its admitted routes and locally originated advertisements. Actual kernel installation and remote reachability are separate from a BGP Established state.

Conditions and references

  • Live operation currently supports one BGPRouter and no VRF. Validator acceptance of distinct ASN/VRF/listen instances does not imply runtime support.
  • Router import, connected redistribution and static redistribution prefix lists cannot overlap across these three groups. Masked duplicates within prefix lists are rejected.

Field meaning and default

YAML Field meaning and default
spec.importPolicy Optional router-wide import policy inherited by peers without an override. Empty installs no router import filter, but does not itself authorize every received route for kernel FIB installation.
spec.importPolicy.allowedPrefixes Optional IPv4/IPv6 CIDR allowlist. Import matches the prefix and its permitted more-specific lengths; masked duplicate prefixes are rejected. Empty adds no prefix match condition to an otherwise configured import policy.
spec.importPolicy.allowedPrefixLengthMin Integer 0–128; 0/omitted uses each allowlist prefix length. A positive value must be >= each listed prefix length, <= address-family maximum and <= a positive maximum.
spec.importPolicy.allowedPrefixLengthMax Integer 0–128; 0/omitted uses 32 for IPv4 or 128 for IPv6. A positive value must cover every listed prefix length and not exceed its family maximum. Dynamic leaf admission requires min=max=32.
spec.importPolicy.requiredCommunities Optional community list; an accepted path must contain ALL listed communities. Empty adds no required-community condition.
spec.importPolicy.forbiddenCommunities Optional community list; ANY matching community rejects the path before the accept rule. Empty adds no prohibition.
spec.importPolicy.nextHopRewrite peer-address by default; unchanged preserves the advertised next hop. Applied on accepted paths before selection/FIB projection. Setting only this field on a peer creates a peer-specific import policy instead of inheriting the router allowlist.
spec.importPolicy.localPreference Optional uint32 LOCAL_PREF for accepted paths before best-path selection. Default 0 leaves the BGP implementation default unchanged.
spec.exportPolicy Optional export prefix filter. Per-peer prefixes are combined with router static and dynamic advertisements; route-reflector clients also receive router import prefixes. It is not a restrictive replacement for all router-derived export prefixes.
spec.exportPolicy.allowedPrefixes Explicit local advertisement CIDRs, default empty. Combined with redistribute.connected/static and dynamic advertisements, and also used in peer export filtering; these prefixes are originated without an OS-route existence check.
spec.timers Optional timer-profile object. Router-level timers are not inherited by peers in the current controller; specify each peer timer profile explicitly when needed.
spec.timers.profile Accepted default/fast/slow, but router-level timer settings are not used to build peer timers in the current runtime. Configure BGPPeer.timers.profile or BGPDynamicPeer.timers.profile instead.
spec.when Optional common activation predicate; omitted is unconditional. See common fields for state/all/any, reference validation and schema limitations.
spec.asn Required nonzero uint32 local ASN. Configuration rejects reuse across BGPRouter resources; runtime currently supports one BGPRouter only.
spec.routerID Required IPv4-form BGP router identifier; independent of the transport address. BFD without an interface also uses it as the local multihop address.
spec.vrf Optional VRF/name or plain VRF name referencing a declared VRF. Validation supports it, but the operational GoBGP controller currently rejects any nonempty vrf as GoBGPVRFUnsupported. Omit for live use.
spec.listen Optional local TCP listener configuration; default all addresses, port 179. Does not select the remote peer TCP port.
spec.listen.address Optional local IPv4/IPv6 bind address. Empty leaves GoBGP listening on all addresses; must be an IP, not a resource reference or hostname.
spec.listen.port TCP listen port 1–65535, default 179 when omitted/0. Conflicting configured address/port claims are rejected.
spec.redistribute Optional explicitly advertised prefix groups. Current runtime unions connected/static lists with exportPolicy.allowedPrefixes; it does not discover matching routes from the OS.
spec.redistribute.connected Optional connected-labelled advertisement group; default empty. The label does not gate advertisements on kernel connected-route presence.
spec.redistribute.connected.allowedPrefixes Explicit IPv4/IPv6 CIDRs to originate, default empty. Cannot overlap router import or static redistribution prefixes. Does not require a corresponding connected route.
spec.redistribute.static Optional static-labelled advertisement group; default empty. Not an automatic scan of IPv4StaticRoute/IPv6StaticRoute resources.
spec.redistribute.static.allowedPrefixes Explicit IPv4/IPv6 CIDRs to originate, default empty. Cannot overlap router import or connected redistribution prefixes; no kernel static-route existence check.
spec.communities Optional community settings. Only router set.out affects locally originated advertisements in the present runtime; send, accept and set.in are decoded/validated but unused.
spec.communities.send Accepted values standard, extended, both or empty; no operational effect. GoBGP peers use SendCommunity=3 regardless of this setting.
spec.communities.accept Optional validated standard community list, default empty; currently does not filter import. Use importPolicy.requiredCommunities/forbiddenCommunities for actual matching.
spec.communities.set Optional inbound/outbound community lists; only router out is consumed by the present controller.
spec.communities.set.in Optional validated list, default empty; currently not applied to imported paths.
spec.communities.set.out Standard communities attached to router-created local advertisements, default empty. Does not rewrite every transit route. Use asn:value (standard 16-bit components) or supported well-known names; extended communities are not encoded here.
spec.convergenceProfile default/omitted or stable keeps graceful restart enabled by default; fast disables it unless gracefulRestart.enabled explicitly overrides. It does not automatically select timers.profile.
spec.gracefulRestart Optional graceful restart settings shared with peers after convergence-profile selection. Explicit enabled overrides the profile default.
spec.gracefulRestart.enabled Optional boolean; default true except fast convergence. False disables GR even if durations are specified.
spec.gracefulRestart.restartTime Positive Go duration, default 120s, converted to whole seconds by truncation. Subsecond values can therefore become 0; use whole-second values.
spec.gracefulRestart.stalePathTime Positive Go duration for stale-route retention, default 360s; converted to whole seconds. Ignored when GR is disabled.
spec.watcher Optional status-observation settings; these are not BGP keepalive/hold timers or peer admission limits.
spec.watcher.pollInterval Go duration >=3s. Effective polling starts at 15s and only decreases for smaller configured values, so values above 15s do not lengthen the interval.
spec.watcher.maxPrefixes Observation prefix limit, default 4096; explicit positive values must be <1000000. Does not configure a remote session maximum-prefix shutdown policy.
spec.watcher.peerStateChangeThrottle Nonnegative Go duration limiting repeated peer-state event publication; omitted/0 has no throttling. Does not delay the BGP protocol state machine.
spec.backend gobgp by default and the only accepted backend. Uses the routerd-bgp daemon/control client, not an FRR BGP configuration file.
