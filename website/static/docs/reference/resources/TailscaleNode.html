TailscaleNode

Resource configuration reference · Kind/name · when · dependsOn

apiVersion: net.routerd.net/v1alpha1 · metadata.name

Manage Tailscale enrollment options through a routerd-generated systemd oneshot on Linux or rc.d script on FreeBSD, then observe tailscale status --json. Tailscale/Headscale server-side approvals remain separate.

Conditions and references

  • authKey is mutually exclusive with authKeyEnv and authKeyFile. authKeyEnv and authKeyFile may be combined: the former chooses the variable read from the latter; without authKeyEnv, a supplied file uses TS_AUTHKEY.
  • authKeyFile is an environment-variable assignment file, not a raw key. Use TS_AUTHKEY=tskey-... (or the authKeyEnv variable). On FreeBSD use one unquoted assignment on its own line; missing, duplicate or empty selected values fail. On Linux it is loaded as systemd EnvironmentFile.
  • A present node reserves UDP 41641 against configured listener conflicts. The generated command uses tailscale up --timeout=30s. Applied/Rendered describes service application, while Running is reported only after observing BackendState=Running; neither proves an advertised subnet is reachable.
  • FreeBSD rc.d refuses mutation of a pre-existing tailscaled process whose routerd ownership marker is absent. Linux uses the shared tailscaled.service and a routerd-tailscale-.service enrollment unit. state: absent removes the enrollment unit; it is not a package-uninstall or tailnet node-deletion request.

Configuration syntax

This is explanatory notation, not YAML to copy. Unbracketed fields are required within their parent; [ ... ] marks fields that can be omitted, subject to the conditions in the table. <type> is a placeholder, and (a | b) lists alternatives. Optional parents may contain required children. Conditional requirements, exclusions and runtime defaults are described below. Use the linked YAML example for an ordinary configuration.

- apiVersion: net.routerd.net/v1alpha1
  kind: TailscaleNode
  metadata:
    name: "<name>"
  spec:
    [ acceptDNS: <boolean> ]
    [ acceptRoutes: <boolean> ]
    [ advertiseExitNode: <boolean> ]
    [ advertiseRoutes:
        - <string>
    ]
    [ advertiseTags:
        - <string>
    ]
    [ authKey: <string> ]
    [ authKeyEnv: <string> ]
    [ authKeyFile: <string> ]
    [ hostname: <string> ]
    [ loginServer: <string> ]
    [ shieldsUp: <boolean> ]
    [ ssh: <boolean> ]
    [ state: ("" | "present" | "absent") ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

Field meaning and default

Required children of optional objects apply only when their parent is used. Other exact conditions are in the explanation; bracketed alternatives may still require one choice.

YAML Presence Type / constraints Field meaning and default
spec.state Optional string; enum=["", "present", "absent"] present by default; absent removes the managed enrollment service. No package removal or control-server node deletion is performed by this field.
spec.hostname Optional string Optional tailscale up --hostname value, not Router.metadata.name or an OS hostname change. Omitted leaves the flag absent.
spec.loginServer Optional string Optional control-server URL for --login-server, for example a Headscale server. Omitted delegates to the Tailscale client configuration/default; routerd provides no URL default or resource lookup.
spec.authKey Optional string Optional inline enrollment key; excludes authKeyEnv/authKeyFile. Omitted supplies no key flag unless another key source is configured; existing client login state or interactive enrollment requirements then apply.
spec.authKeyEnv Optional string Optional environment variable name for the enrollment key, not the key itself. May select a variable from authKeyFile. Linux uses the generated service environment; this does not automatically copy routerd process environment into that service.
spec.authKeyFile Optional string Optional absolute environment-file path on the router; selected variable defaults to TS_AUTHKEY. Use a simple unquoted NAME=value line for Linux/FreeBSD portability. Not a Secret resource reference.
spec.advertiseExitNode Optional boolean Default false; true emits --advertise-exit-node. Does not approve exit-node use on the control server or make this router use another exit node.
spec.advertiseRoutes Optional array Optional IPv4/IPv6 CIDR list passed as comma-separated --advertise-routes. Empty omits the flag, rather than explicitly passing an empty route list. Required control-server approval is separate.
spec.advertiseTags Optional array Optional tag strings passed as comma-separated --advertise-tags. Validator rejects empty/whitespace entries but does not enforce a tag: prefix or verify server ACL permissions. Empty omits the flag.
spec.acceptRoutes Optional boolean Optional boolean for --accept-routes. Omitted leaves the flag absent and delegates behavior to the Tailscale client; explicit false is emitted, unlike omission.
spec.acceptDNS Optional boolean Optional boolean for --accept-dns. Omitted does not force either true or false; explicit values are passed to the client. This does not configure routerd DNSResolver/DNSForwarder resources.
spec.ssh Optional boolean Default false omits the flag; true emits --ssh to request Tailscale SSH. This is separate from OS sshd and routerd management access.
spec.shieldsUp Optional boolean Optional boolean for --shields-up; omission leaves the client flag unset, while explicit true/false is emitted.
spec.when Optional object Optional common activation predicate; omission is unconditional. Consult common fields for state/all/any and field-reference rules. It gates the generated service rather than deleting a tailnet node.
