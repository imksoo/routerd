NTPServer

リソース別の設定 · Kind/name · when · dependsOn

apiVersion: system.routerd.net/v1alpha1 · metadata.name

chronyまたはFreeBSD ntpdを使い、時刻サーバーと上流サーバーを設定します。

指定条件と参照関係

  • managedの既定値はfalseです。trueでは上流の取得元宣言が必要で、staticならserversが追加で必須です。待受・許可元の配列は結合しますが、上流の各取得方法はsourceの選択順で切り替えます。
  • ntpdの生成処理はallowCIDRsによる制限を出力しません。この一覧の宣言だけでntpdへのクライアント制限が適用されるとは扱わないでください。
  • 動的なsourceでは、上流の値が未解決でも、それだけでサーバー設定の生成を止めません。上流なしの設定になる場合があります。Appliedは設定・サービスの反映を示し、時刻同期済みの証明ではありません。

設定構文

説明用の構文表記であり、そのままコピーするYAMLではありません。囲みのない項目は親の中で必須、[ ... ]は条件に応じて省略できる項目、<型>は差し替え値、(a | b)は選択肢です。任意の親にも必須の子があります。条件付き必須・排他・実効既定値は下の表を確認し、通常のYAMLはリンク先の設定例を使ってください。

- apiVersion: system.routerd.net/v1alpha1
  kind: NTPServer
  metadata:
    name: "<name>"
  spec:
    [ allowCIDRFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ allowCIDRs:
        - <string>
    ]
    [ fallbackServers:
        - <string>
    ]
    [ listenAddressFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ listenAddresses:
        - <string>
    ]
    [ managed: <boolean> ]
    [ provider: ("chrony" | "ntpd") ]
    [ serverFrom:
        -
          field: <string>
          [ optional: <boolean> ]
          resource: <string>
    ]
    [ servers:
        - <string>
    ]
    [ source: ("static" | "auto" | "dhcp" | "dhcpv6") ]
    [ when:
        [ state:
            [ <name>:
                [ contains: <string> ]
                [ equals: <string> ]
                [ exists: <boolean> ]
                [ for: <string> ]
                [ in:
                    - <string>
                ]
                [ maxAge: <string> ]
                [ status: ("set" | "unset" | "unknown") ]
            ]
        ]
    ]

項目の意味と既定値

任意の親の必須項目は、親を使う場合に必要です。それ以外の具体的な条件は説明欄に記載します。[ ... ]で囲まれた選択肢も、いずれか一方が必要な場合があります。

YAML 指定要否 型・制約 項目の意味と既定値
spec.managed 任意 boolean 省略時falseで、時刻サービスを設定・起動せずObservedを記録します。ファイルとサービスを管理する場合はtrueにします。
spec.source 任意 string; enum=["static", "auto", "dhcp", "dhcpv6"] 省略時staticでserversを使います。auto・dhcp・dhcpv6はいずれも、解決したserverFrom、fallbackServers、serversの順で選びます。DHCPの取得元を自動探索する指定ではありません。
spec.servers 条件付き必須 array 上流サーバーのホスト名またはIPアドレス。省略時は空ですが、managed=trueかつsource省略/staticでは必須です。各要素は空白を含まない単一の値で、リソース参照ではありません。
spec.serverFrom 任意 array 明示する値の取得元一覧。省略時は空です。例はDHCPv4Client/wanのntpServers、DHCPv6PrefixDelegation/wan-pdのsntpServersです。auto/dhcp/dhcpv6で使い、各resourceとfieldの存在が必要です。 この取得処理はoptionalを使わず、値がなければ次の取得方法へ進みます。
spec.when 任意 object 有効化条件。省略時は条件を設けません。state/all/any、unknown、経過時間の条件は共通の条件指定を参照してください。
spec.provider 任意 string; enum=["chrony", "ntpd"] サーバー実装。通常はchrony、FreeBSDではntpdが既定値です。ntpdはFreeBSDでのみ対応します。
spec.fallbackServers 任意 array 代替上流の一覧。省略時は空です。auto/dhcp/dhcpv6でserverFromに値がないとき、serversより先に選びます。独立した代替指示は生成しません。
spec.listenAddresses 任意 array 固定の待受IPアドレス。省略時は空です。CIDRはホスト部分のIPへ変換します。待受設定が空ならbindaddress/interface listen指示を生成せず、実装サービスの既定動作を使います。
spec.listenAddressFrom 任意 array 追加の待受アドレス取得元。省略時は空で、listenAddressesと結合します。各要素のresourceとfieldが必要です。待受設定を宣言したのに結合結果が空ならPending/NoListenAddressesです。
spec.allowCIDRs 任意 array 利用を許可するクライアントのCIDR一覧。省略時は空です。chronyでは各allowを生成しますが、ntpdの生成設定にはこの一覧を使いません。固定値の入力検証は空白でないことまでで、CIDR構文は確認しません。
spec.allowCIDRFrom 任意 array allowCIDRsと結合するCIDR取得元。省略時は空です。optionalでない取得元に値がなければPending/AllowCIDRFromPending、取得値が不正なCIDRならPending/AllowCIDRFromInvalidです。プレフィックス長のないIPアドレスはCIDRとして受理しません。

実装: pkg/api/specs.go · pkg/config/validate_system.go · pkg/controller/chain/ntp.go

状態値の参照に使えるフィールド

通常の状態値参照の検証で、このKindについて許可するフィールド名です。許可一覧にあるだけでは値の生成・取得を保証しないため、実際の状態を確認してください。YAMLのspecに設定する項目ではなく出力です。

phase, servers, listenAddresses, allowCIDRs, source, updatedAt
