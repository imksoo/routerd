宣告式網路設定

用 YAML 定義路由器設定。

將介面、位址、路由、DHCP、DNS及防火牆規則整合為一份設定。檢查變更計畫、套用設定，並觀察路由器的運作狀態。

開始使用 →設定參考
router.yaml介面與位址範例
apiVersion: routerd.net/v1alpha1
kind: Router
metadata:
  name: example
spec:
  resources:
    - apiVersion: net.routerd.net/v1alpha1
      kind: Interface
      metadata:
        name: lan
      spec:
        ifname: ens18
        managed: true
        adminUp: true
    - apiVersion: net.routerd.net/v1alpha1
      kind: IPv4StaticAddress
      metadata:
        name: lan-address
      spec:
        interface: lan
        address: 192.0.2.1/24
套用前，請將介面名稱與位址改為實際環境的值。

驗證YAML、檢查變更計畫，再套用完整設定。之後確認狀態與實際連線。--replace只用於路由器的完整設定。
