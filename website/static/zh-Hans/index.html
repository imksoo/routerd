声明式网络配置

用 YAML 定义路由器配置。

将接口、地址、路由、DHCP、DNS及防火墙规则整合为一份配置。检查变更计划、应用配置，并观察路由器的运行状态。

开始使用 →配置参考
router.yaml接口与地址示例
apiVersion: routerd.net/v1alpha1
kind: Router
metadata:
  name: example
spec:
  resources:
    - apiVersion: net.routerd.net/v1alpha1
      kind: Interface
      metadata:
        name: lan
      spec:
        ifname: ens18
        managed: true
        adminUp: true
    - apiVersion: net.routerd.net/v1alpha1
      kind: IPv4StaticAddress
      metadata:
        name: lan-address
      spec:
        interface: lan
        address: 192.0.2.1/24
应用前，请将接口名与地址改为实际环境的值。

浏览YAML示例 →

应用前，先检查计划。

验证YAML、检查变更计划，再应用完整配置。之后确认状态与实际连接。--replace仅用于路由器的完整配置。

routerd validate --config router.yaml
routerctl plan -f router.yaml --replace
routerctl apply -f router.yaml --replace
routerctl get status
